# Voice Assistant for Windows

A Python voice assistant for Windows that uses speech recognition and AI to interact with desktop apps, identify controls, and perform actions based on user voice commands for hands-free automation.

## Features

- **Speech Recognition**: Listen and understand user voice commands in real time.
- **AI-driven Actions**: Uses artificial intelligence to map spoken requests to desktop actions.
- **App Control**: Interact with and automate Windows applications hands-free.
- **UI Element Identification**: Find and manipulate controls and buttons in supported apps.
- **Automation**: Perform routine tasks, open apps, type text, and execute shortcuts with your voice.
- **Customizable Commands**: Add or modify voice commands for personalized automation.

## Tech Stack

- **Python** (core logic & backend) 
- **JavaScript** (frontend interactions) 
- **CSS** (styling) 
- **HTML** (markup) 

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/srivastavaprakhar/voice_assistant.git
   cd voice_assistant
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Run the assistant**
   ```bash
   python main.py
   ```

4. **Start speaking!**
   - Use your microphone to give voice commands.
   - The assistant will respond and perform actions on your Windows desktop.

## Example Commands

- "Open Chrome"
- "Type 'Hello, world!' in Notepad"
- "Click the OK button"
- "Switch to the next window"
- "Play music"

## Requirements

- Windows OS
- Python 3.8+
- Microphone
